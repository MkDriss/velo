# Projet Velo

## Lancer le projet

### Prérequis

- ActiveMQ version 6.1.8 doit être lancé.
- Python 3 doit être installé (pour héberger un serveur web).

### Étapes

1. Pour lancer le **Frontend** ainsi que le **Producer ActiveMQ** pour la météo, exécutez :

```
./start.bat
```

2. Pour lancer le **serveur GPS**, exécutez :

```
./GPS_Server.exe
```

3. Pour accéder au frontend, ouvrez votre navigateur à l'adresse :

    [http://localhost:8080/](http://localhost:8080/)
